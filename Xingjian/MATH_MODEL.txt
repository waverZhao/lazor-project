Lazor 数学模型与安全剪枝说明

对应代码：constraint_solver.py。
这是一套约束可行性模型，不含最少方块、最短路径等优化目标。

1. 每个可放位置选一种类型

给原始棋盘中每个 o 格子 c 一个整数变量 t[c]：
  t[c] in {0, 1, 2, 3}
  0=空，1=A反射块，2=B遮挡块，3=C分光块。
原始固定A/B/C用常量表示，不加入可移动库存。x也用空格常量表示，
它禁止摆方块，但仍允许光经过。

2. 库存必须恰好用完

每种方块 k：
  sum(If(t[c] == code[k], 1, 0) for c in 可放位置) == 库存[k]
因此不会凭空增加方块、遗漏库存，也不会让一个格子同时出现两种类型。

3. 光线的有限状态空间

状态 s = (x, y, vx, vy)，其中 vx、vy分别取-1或1。
0 <= x <= 2W，0 <= y <= 2H，x+y为奇数。
W/H是整格宽高；激光使用半格坐标，原点在左上角。
总状态数 N = 4 * (2*W*H + W + H)。
每个状态同时记住位置和方向，避免把同一点的不同走向混为一谈。

4. 条件光学边

在状态s处，根据方向得到前方格子front(s)。若x为偶数，碰到竖直面；
否则碰到水平面。

直行方向 = (vx, vy)。
反射方向 = (-vx, vy)，当碰到竖直面；
反射方向 = (vx, -vy)，当碰到水平面。

前方为空或C：允许直行分支。
前方为A或C：允许反射分支。
前方为B：无出射分支。

每条分支还需要：
  下一点没有越界；
  该出射方向实际穿过的格子为空或C。
后一个条件与simulate一致，处理光源夹在相邻方块之间的情况。
把“方块类型允许这条边”的公式记为 g(u, v)。

5. 可达性与来源证明

给每个状态s布尔变量 R[s]：实际光能否从某个光源到达它。
再给整数 h[s]：证明它有光源来源的层级，不是物理时间步数。

光源s：
  R[s] = True，h[s] = 0。

对每条候选边u->v，写前向闭包：
  R[u] AND g(u,v)  =>  R[v]
所以C的两个有效分支都必须传播，不能为满足某个目标而随意舍弃一支。

每个可达的非光源状态v，还必须有至少一个前驱u：
  R[u] AND g(u,v) AND h[u] < h[v]
且1 <= h[v] < N。不可达的非光源状态层级设为-1。

为什么需要这一条？
如果只有“前驱能亮所以我能亮”，孤立镜环可能互相支持，被错误地全部
标为可达，即使它根本没有连接任何光源。严格降低的前驱层级会一直追溯
到光源，阻止这种凭空出现的光。

为什么不会误删真实镜环？
每个状态只需要“存在一个”层级更低的来源前驱，而不是每条光学边
都必须增加层级。连接到光源的真实闭环仍可通过一棵来源树得到证明。

6. 所有目标至少有一个方向可达

对目标坐标(x,y)：
  OR(R[(x,y,vx,vy)] for 四个方向中的合法状态) == True
如果目标根本不在状态空间中，这个OR为空，即False，整个模型无解。
目标可以被任意光源或分光分支命中，光源自身的位置也算经过。

7. 解出来后独立验证

从t[c]取出A/B/C位置，调用simulate(puzzle, placements)。
检查is_solution()，并且核对：
  模型可达状态 == 模拟光源与有向线段推出的全部状态；
  模型经过点 == 模拟visited_points；
  模型有效有向边对应线段 == 模拟segments。
不只检查几个目标点，避免模型隐藏错误光路。

8. 可选的源不可达状态裁剪

先取所有没有被静态判为False的候选边，暂时不要求这些边的守卫条件
能同时成立；从所有光源遍历这个宽松图，得到保留集合K。
它是一切实际光路的超集。

安全性理由：任何真实可走的边都在候选图中，因此真实可从光源到达的
状态一定在K里。不在K里的状态，不可能在任何合法摆法中被光照到。
删除这些状态及相关边，再为K重建库存、前向闭包、来源与目标约束。
光源不能删；不可达目标仍必须导致UNSAT，不能把它的约束一起丢掉。

当前实验实现先构建完整模型，再重建小模型。变量减少，但多了一次
构建成本，可能更慢。比较时要看完整elapsed_seconds，而不是只看
solver_seconds。不同模式也可能返回不同的有效解，不能要求摆法相同。

9. 不要直接采用的错误“剪枝”

“目前这个部分摆法没有命中所有目标，所以直接丢掉”不成立。
尚未放置的A/C方块可能改变方向或分光，让目标在最终摆法中被命中。
若要做部分摆法剪枝，应采用保守的可达性上界等必要条件，并用小棋盘
全枚举证明没有漏解。不能把暂时失败当作最终无解。

同样，不能通过限制一个随意的最大步数来排除光路循环，也不能删掉
rank来源证明、把所有边都强制成层级递增，或只保留C的一条分支。
